Bruce Jones Home Automation Alerts

This is a private, non-commercial home automation notification program operated by Bruce Jones for the sole use of himself and members of his immediate household. It is not offered to the public.

The program sends automated text message alerts triggered by home automation events such as security, environmental, and pet-related conditions.

Authorized household members can sign up to receive these SMS alerts using the registration page below. The registration form includes the SMS call to action and requires affirmative consent before a mobile number is submitted.
